# Indel benchmark raw data (seeds 100–129, n=200)

## Contents

- `seed{N}_indel.fasta` — unaligned simulated sequences (n=200 taxa per file), N = 100–129
- `seed{N}_indel_true.nwk` — the corresponding true (simulation) tree in Newick format

These are the authoritative inputs for the 130-seed n=200 indel benchmark
(manuscript Table 3 / Figure 2, seed range 100–229; this archive covers
seeds 100–129).

## How the data was actually generated (important)

The sequences were generated by the **deterministic Python simulator
`scripts/gen_test_data_indel.py`** (included in this package), not by the
INDELible binary. Per-seed generation is fully deterministic: given the same
seed, the script regenerates byte-identical FASTA and true-tree files (this
property was used and verified during the June 2026 storage-corruption
recovery — regenerated files matched the intact originals byte-for-byte).

Simulation parameters (as logged in DATA_PROVENANCE.csv):

| Parameter | Value |
|---|---|
| substitution model | JC69 |
| substitution rate | 0.05 |
| sequence length L | 500 bp |
| taxa n | 200 |
| indel rate | 0.02 (per branch, Poisson count = rate × branch_length × L) |
| indel length distribution | geometric, mean = 3 bp (max 50) |
| indel type | 50% insertion / 50% deletion |
| tree prior | random coalescent-like topology, uniform branch length 0.1 |

To regenerate seed 100:

```
python scripts/gen_test_data_indel.py 200 500 0.05 0.02 100
```

## Note on manuscript wording

The manuscript Methods section describes the simulation as "INDELible under
GTR+Γ with birth-death tree priors". The archived FASTA/true-tree files in
this directory are the actual benchmark inputs; the deterministic Python
simulator above is the actual generator of record. (Flagged for Methods-text
correction in v3.1.)
