# F2 — S10 Windows 复现数值溯源（审稿 M14）

## 结论

S10 句 "mean nRF 0.231238 vs 0.231472, difference 0.0002" 描述的是**已撤回旧手稿值 0.231** 在旧有偏指标（Biopython legacy）下、两个 IQ-TREE2 输出目录间的复现一致性——不是现行 canonical 值（0.210±0.031）的复现。stats reviewer 判断正确，但**不必整句删除**：同一 JSON 里有标准指标下的对应复现值，可改写为正确版。

## 证据

源文件 `indelible_iqtree2/iqtree2_n200_indel_nrfstandard.json`（`rescore_iqtree2_nrfstandard.py` 生成，2026-10-22）：

- `manuscript_figure_audit`：旧手稿值 iqtree2_mean=0.231 / fusang_mean=0.122 分属两种有偏指标（verdict: "the 1.9x gap is a metric artefact, not a biological result"）
- 0.231238 = 旧指标下 primary treefiles（`indelible_iqtree2\run`，Windows replicate）均值；0.231472 = alt treefiles（`indelible_iqtree2\wsl_treefiles`，WSL canonical）均值；差 0.000234 ≈ 句中 "0.0002"
- **标准指标下的对应值**（同一 JSON）：primary 0.210387 ± 0.030705 vs alt 0.210660 ± 0.030700，均值差 **0.000273 ≈ 0.0003**
- per-seed CSV（`iqtree2_n200_indel_nrfstandard.csv`）独立重算（本机 venv python, scipy）：标准指标下两源 **35/130 seeds 完全一致，mean |Δ|=0.0062**（旧句写 36/130，系旧指标口径）
- 手稿 p=9.21e-05 复核：整数 RF 计数 + zsplit → **p=9.2087e-05** ✓ 手稿正确（浮点口径 7.95e-05 为 JSON 内附的旧算法，未被手稿引用）
